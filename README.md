# tic-tac-toe
A simple command line implementation of Tic-Tac-Toe in Ruby


Player 1 selects X's or O's
Player 2 receives the other game piece by default
The blank board is drawn with coordinates for triangulation

Loop until Three in a row OR no moves left:
    X player is asked where they would like to move
    Board is updated
    O player is asked where they would like to move
